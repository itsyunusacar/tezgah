## [0.1.0] - 2026-11-04

The first beta of Tezgah: a terminal for working with AI coding agents, on macOS, Windows and Linux.

- Projects and sessions in a sidebar, each agent's live status (working, needs you, done), and Allow or Deny for Claude Code's permission prompts from the sidebar. Status for Codex through hooks, and for Gemini, Grok, Aider, OpenCode and others from what they do.
- Panes that go anywhere: split, drag one by its bar to any side of another, or move it with ⌃⌘ and an arrow. Terminal, browser and screen panes.
- Screen panes: watch another window live beside the agent driving it, like Unity, a simulator or the display an agent's computer use works on.
- A browser pane your agents can drive (`tezgah browser`, or Tezgah's tools in Claude Code), locked down: websites get no camera, microphone or clipboard, and a local page reads only its own folder.
- Terminals outside any project (⌘N), search across projects and sessions (⇧⌘F), links that open with a click, and a right-click menu with Copy and Paste.
- The Changes panel: review, commit and push, with worktree sessions you can merge back.
- Plan limits for Claude and Codex in the sidebar, with when they reset.
- Finder's Quick Actions → Open in Tezgah on any folder, and Tezgah as the default terminal for shell scripts and ssh:// links (Settings).
- Updates that install themselves when you quit, and a Mac app signed with Tezgah's own certificate, so macOS keeps the permissions you give it.
- English and Turkish.
